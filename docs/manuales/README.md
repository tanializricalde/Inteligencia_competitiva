# Manuales de usuario

Estos documentos describen las funciones visibles de la aplicación para usuarios finales y
administradores funcionales. Para instalación, actualización y respaldo consulte las
[guías de operación](../operations/README.md).

| Manual | Audiencia | Contenido |
| --- | --- | --- |
| [Portal principal](manual-portal-principal.md) | Analistas, operadores y administradores | Acceso, navegación, dashboard, reseñas, pipeline, fuentes, ejecuciones, configuración, flujos y solución de problemas. |
| [Django Admin](manual-django-admin.md) | Personal staff y administradores | Uso seguro del Admin, permisos, los modelos registrados, relaciones, restricciones y diagnóstico. |

Los marcadores `[CAPTURA-...]` indican imágenes que sólo deben sustituirse usando una base demo
sanitizada. No use datos reales, correos, nombres de autores, comentarios ni evidencia operativa en
capturas de documentación.
